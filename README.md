# 네모팩토리 (Nemo factory)

`nemofactory.co.kr` 회사 사이트입니다.

- **상호** 네모팩토리 (Nemo factory)
- **대표자** 양성민
- **문의** contact@nemofactory.co.kr

일상을 더 편리하게 만드는 모바일 앱을 만듭니다. App Store 와 Google Play 에서 만나보세요.

## 이 저장소가 서비스하는 것

| 파일 | 쓰임 |
|---|---|
| `index.html` | 회사 소개 · 앱 목록 · 사업자 정보 |
| `app-ads.txt` | 광고 네트워크 소유권 확인 (IAB app-ads.txt) |
| `app-status.json` | 앱 최소 지원 버전 안내 |
| `hiking-closure.json` | 등산가자 입산 통제 정보 |
